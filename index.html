🧩 Malla Builder Web

Formulario amigable para cargar requerimientos de una malla Control-M — sin editar el Excel a mano. Los datos se guardan en una Google Sheet propia (vía Apps Script) o se pueden importar directo desde el Excel real de BCI. Con cualquiera de los dos orígenes, esta página genera el mismo XML (Definition Table) y JSON (Automation API) que el módulo Malla Builder local de ArgOS.

⛓ Excel real o Google Sheet (formulario amigable) → jobs normalizados → XML / JSON Control-M → vista Planning simulada
